# zhhskill

Five AI assistant skills for working with Obsidian:

- `obsidian-markdown`: Obsidian-flavored Markdown
- `json-canvas`: JSON Canvas files, mind maps, and flowcharts
- `obsidian-bases`: Obsidian Bases views, filters, and formulas
- `defuddle`: Clean Markdown extraction from web pages
- `obsidian-cli`: Obsidian vault and CLI operations

These are skills for AI coding assistants such as Codex, Claude Code, and
Cursor. They are not Obsidian plugins.
