# zhhskill

A personal collection of Agent Skills for Codex, Claude Code, Cursor, and
other compatible AI assistants.

## Included

The repository contains the original Obsidian skills plus the skills collected
from the recommended list:

- Browser and internet: `agent-browser`, `agent-reach`, `find-skills`
- Content and writing: `dbs-content`, `humanizer`, `impeccable`
- Documents and slides: `docx`, `pdf`, `pptx`, `xlsx`, `baoyu-design`,
  `guizang-ppt-skill`
- Video: `hyperframes` and the Remotion skill set
- Agent workflows: `gstack`, `skill-creator`, and the Superpowers skill set
- Obsidian: `obsidian-markdown`, `json-canvas`, `obsidian-bases`,
  `defuddle`, `obsidian-cli`

Each directory under `skills/` is a self-contained skill package with a
`SKILL.md` entrypoint. Supporting references, scripts, and assets remain next
to the skill that uses them.

## Notes

- Upstream license and attribution files are kept inside their respective
  skill directories.
- Some skills require external tools, runtimes, credentials, or platform
  access. Read the skill's `SKILL.md` before use.
- These are instructions and resources for AI assistants, not standalone
  applications or Obsidian plugins.
